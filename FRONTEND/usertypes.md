Core user types (recommended)

Super Admin – system owner, full access, licensing, master settings.

Admin (ERP Admin) – user/role management, plant settings, masters, approvals.

Sales / Customer Support – leads, quotations, order confirmation, customer communication.

CAM / DFM Engineer – file check, stackup validation, tooling, panelization, CAM outputs.

Production Planner – converts orders → work orders, routing, scheduling, capacity planning.

Shopfloor Operator – updates stage progress (imaging, etch, drill, plating, soldermask, etc.).

Quality (QA/QC Inspector) – AOI, E-test, final inspection, NCR, rework approvals.

Stores / Inventory – receiving, stock ledger, issue to production, reorder levels.

Procurement / Purchase – vendors, purchase orders, GRN, pricing, lead time tracking.

Dispatch / Logistics – packing, shipping labels, courier, delivery status.

Finance / Accounts – invoicing, payments, GST, credit notes, cost reports.

Maintenance Engineer – machine PM schedules, breakdown logs, spares consumption.

Optional (if needed)

Management (Owner/Plant Head) – read-only dashboards, KPIs, approvals.

Customer Portal User – customers upload Gerbers, track order, download invoices.

Warehouse Packer – packing checklist + batch/label scan.

HR / Attendance Admin – attendance, leave, payroll (only if you keep HR module inside ERP).
